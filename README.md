# Web Projekt "Smotra" (Natječaj 2017.)

Profesionalni web projekt izrađen 2017. godine u svrhu sudjelovanja na natječaju. Projekt predstavlja statičnu web stranicu razvijenu primjenom temeljnih web tehnologija.

## O projektu

Projekt je razvijen kao rješenje za natječaj održan 2017. godine. Glavni cilj bio je izraditi responzivno, funkcionalno i vizualno usklađeno korisničko sučelje.

## Tehnologije

Tijekom razvoja korišteni su sljedeći alati i tehnologije:

* **HTML5** – Struktura i semantika web stranice
* **CSS3** – Stilsko oblikovanje i responzivni dizajn
* **JavaScript (ES6)** – Interaktivnost i klijentska logika
* **Brackets** – Primarni izvorno okruženje (IDE) za razvoj

## Struktura projekta

## Pokretanje projekta

Za pregled web stranice na lokalnom računalu nije potrebna instalacija dodatnih zavisnosti:

1. Klonirajte ili preuzmite spremište (repository).
2. Otvorite datoteku `index.html` u bilo kojem modernom web pregledniku (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
